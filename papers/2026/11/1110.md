# Learning Heterogeneous Tactile Representation for General Dexterous Manipulation

> 推荐日期：2026-11-10 | 来源：arxiv | 引用数：0
> 推荐理由：首个显式将磁触觉纳入统一触觉基础模型的工作，其"跨传感器统一表征"思路直接关系到我们磁触觉数据能否复用大规模预训练范式。

## 一句话核心贡献
提出跨压阻/磁/视触觉传感器的统一触觉基础模型 LingBot-Touch，输出即插即用的触觉 token。

## 与我们工作的关系
- **相同点**：都把磁触觉信号作为核心输入模态之一，目标都是为下游灵巧操作策略提供可用的触觉表征；都涉及从原始触觉信号到高层特征的映射学习。
- **不同点**：我们的路线是"磁触觉→MLP/CNN→位置/力回归"的监督式物理量预测，输出是显式的接触位置与力；本文是"多传感器→统一 token 表征→下游策略"的表征学习路线，输出是隐式 token，不直接回归物理量，且强调跨传感器泛化而非单一传感器精度。
- **可借鉴的技术/思路**：跨传感器对齐的表征学习目标（把磁触觉与压阻/视触觉拉到同一隐空间）可能为我们的磁场数据提供更强的预训练信号；token 化接口设计可参考其"plug-and-play"接入下游策略的方式。

# BAT-WAM: Bridging Action and Touch in World-Action Models for Dexterous Hands

> 推荐日期：2026-11-10 | 来源：arxiv | 引用数：0
> 推荐理由：首次系统性地把"手部状态↔触觉"的相关性建模为双向连续隐空间桥，为磁触觉在模态缺失/预测场景下的补全与预测提供了可直接迁移的架构思路。

## 一句话核心贡献
用RGB条件化的连续隐桥双向连接触觉与动作码本，实现缺失触觉重建与未来触觉预测。

## 与我们工作的关系
- **相同点**：都从"手部状态/动作"与"触觉信号"的强相关性出发，用学习模型建立从状态到触觉（或反向）的映射；都涉及连续回归式的触觉量预测（RMSE 类指标）。
- **不同点**：我们的路线是"磁触觉原始信号 → MLP/CNN → 位置/力"的单向监督回归；BAT-WAM 是生成式世界动作模型框架，用离散码本（codebook）+ 连续隐桥做多模态双向对齐与掩码补全，目标不是直接回归力，而是重建/预测触觉表征，且强依赖 RGB 视觉上下文。
- **可借鉴的技术/思路**：(1) 触觉/动作分离码本 + 共享连续隐桥的双流结构，可用于我们"磁场→力"与"关节角→位置"两路表征的对齐；(2) 掩码重建（fully/partially masked）作为自监督预训练目标，缓解我们磁触觉标注数据少的问题；(3) 用历史动作 + 目标时刻上下文做未来触觉预测的时序建模思路。
- **可在我们数据上验证的方法**：部分可验证——掩码重建预训练与双流隐桥可迁移到 2/4/6 传感器 18D 磁场数据上做自监督预训练；但 RGB 条件分支与我们纯磁触觉设置不匹配，需替换为关节角/历史磁场序列作为条件，属于需适配而非直接复现。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | RGB 图像（场景上下文+手物几何）、关节状态、全手触觉观测（可部分/完全缺失）、历史动作序列 |
| 输出 | 重建的触觉表征、目标时刻未来触觉预测 |
| 模型架构 | 双流结构：触觉流与动作流各自独立 codebook + decoder；RGB 条件化的连续隐空间桥（continuous latent bridge）双向连接两流；视觉作为连续上下文 |
| 关键创新 | 利用"手状态-触觉"相关性，以连续隐桥替代离散对齐，实现缺失模态下的双向学习与触觉重建/预测 |

## 启发点
- **掩码触觉重建作为自监督预训练**：我们磁触觉标注（力/位置真值）获取成本高，可借鉴"随机掩码部分传感器/部分时序 → 重建"的预训练目标，在 18D 磁场原始信号上做无标注预训练，再微调做力预测。
- **双流隐桥对齐状态与触觉**：可把"关节角→位置"与"磁场→力"视为两条流，用共享连续隐空间约束二者一致性，可能提升位置-力联合预测的耦合精度。
- **未来触觉预测的时序条件建模**：以历史动作+目标时刻上下文预测未来触觉，可迁移为我们灵巧手抓取过程中的力前瞻预测模块。
