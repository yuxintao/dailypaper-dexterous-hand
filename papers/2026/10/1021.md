# FreeTacMan: Robot-free Visuo-Tactile Data Collection System for Contact-rich Manipulation

> 推荐日期：2026-10-21 | 来源：semantic_scholar | 引用数：48
> 推荐理由：该工作提供了大规模视触觉+末端位姿配对数据集与可穿戴采集范式，其"触觉-位姿同步"数据组织方式对磁触觉灵巧手的位置/力预测训练数据构建有直接参考价值。

## 一句话核心贡献
提出可穿戴视触觉夹爪+光学位姿追踪的无机器人数据采集系统，构建50任务、10k轨迹的大规模视触觉-位姿配对数据集。

## 与我们工作的关系
- **相同点**：同样关注"触觉信号 + 末端位姿"的同步配对建模，目标都是为接触丰富操作提供可学习的位置/接触状态表征；都强调多模态同步采集对下游策略学习的重要性。
- **不同点**：本质差异在感知模态与任务定位——FreeTacMan 用视触觉（光学）传感器做数据采集系统与数据集构建，不涉及磁触觉信号解耦，也不做从触觉到力/位置的回归建模；我们的路线是磁触觉 + MLP/CNN 做位置/力预测，属于"感知算法"层，而它是"数据基础设施"层。
- **可借鉴的技术/思路**：① 触觉图像与末端位姿的严格时间同步与配对组织方式，可借鉴到我们磁场-位姿数据集的采集协议；② 50任务分层任务设计可作为我们多传感器 demo 任务多样性的参考；③ 可穿戴、无机器人的采集思路可降低我们扩充磁触觉数据的成本。
- **可在我们数据上验证的方法**：部分可验证——其数据组织/同步协议可直接套用到我们 2/4/6 传感器 demo 的数据管线；但其视触觉模型与光学追踪硬件无法在纯磁场 18D 数据上直接复现，需替换传感层。

# Prometheus: Universal, Open-Source Mocap-Based Teleoperation System with Force Feedback for Dataset Collection in Robot Learning

> 推荐日期：2026-10-21 | 来源：semantic_scholar | 引用数：4
> 推荐理由：开源低成本力反馈遥操作数据采集系统，其力反馈数据流与夹爪力传感设计可为磁触觉灵巧手的位置-力预测提供数据采集范式参考，但算法层面与磁触觉路线关联较弱。

## 一句话核心贡献
基于消费级 Vive Tracker 构建开源低成本力反馈遥操作系统，用于机器人模仿学习数据采集。

## 与我们工作的关系
- **相同点**：都关注"力"信号的获取与利用——本文通过夹爪力传感器实时反馈抓取力，与我们用磁触觉阵列预测接触力在"力感知"目标上一致；都服务于机器人学习的数据/算法闭环。
- **不同点**：本文是遥操作硬件系统 + 数据采集工具链，力信号来自单点力传感器且仅用于人类操作者反馈，不涉及从触觉信号到位置/力的学习式预测；我们的路线是磁触觉多通道信号 → MLP/CNN → 位置/力回归，核心是算法建模而非硬件系统。
- **可借鉴的技术/思路**：(1) 力反馈闭环采集的数据组织方式，可作为我们磁触觉-力标注数据采集流程的参考；(2) 开源硬件/软件全栈发布模式，便于我们对比数据采集规范；(3) "力反馈降低 35.77% 抓取力"的量化实验设计思路，可迁移到我们评估力预测精度对下游任务的影响。
- **可在我们数据上验证的方法**：基本不适合。本文无可学习的触觉→力映射模型，无法直接在我们 2/4/6 传感器 18D 磁场数据上训练或验证；仅其数据采集与评估协议可作为外围参考。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | HTC Vive Tracker 2.0 位姿（操作者手部运动）、夹爪嵌入式力传感器实时压缩力数据 |
| 输出 | UR3 机械臂 + Robotiq 夹爪的运动指令；力反馈信号回传至自定义控制器供操作者感知 |
| 模型架构 | 无学习模型；系统为遥操作映射 + 力反馈闭环（硬件+控制软件） |
| 关键创新 | 消费级动捕 + 自定义控制器 + 定制夹爪指（均匀压力分布）实现低成本力反馈遥操作；全栈开源（硬件设计/PCB/部署） |
