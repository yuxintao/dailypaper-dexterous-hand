# Calibration-free per-finger force-feedback slip control for grasping by anthropomorphic hand with tri-axial tactile sensors

> 推荐日期：2026-08-14 | 来源：semantic_scholar | 引用数：1
> 推荐理由：提出了一种免标定、免学习的滑移检测与恢复控制策略，对磁触觉灵巧手在低算力场景下的实时抓取控制具有直接参考价值。

## 一句话核心贡献
提出免标定、免学习的滑移检测与恢复控制方法，仅用三轴力传感器实现灵巧手稳定抓取。

## 与我们工作的关系
- **相同点**：均使用每指三轴力/磁场传感器进行触觉感知，目标都是实现灵巧手的稳定抓取；都关注从原始传感器信号中提取力信息用于控制决策。
- **不同点**：我们采用磁触觉方案（磁场变化→MLP/CNN→位置/力预测），而本文使用压阻式三轴力传感器直接输出力值，且完全摒弃学习路线，采用基于基线差值的解析式滑移检测；我们的核心在感知端（力/位置预测精度），本文核心在控制端（滑移恢复策略）。
- **可借鉴的技术/思路**：① 基线差分法——用初始读数作为动态基线，通过相邻样本的相对变化检测滑移，无需绝对力标定；② 逐指独立闭环控制——每根手指根据自身滑移状态独立增力，避免全局耦合；③ 电机电流保护机制——在增力过程中限制执行器过载，对实际部署有工程参考价值。

# Real-Time Detection and Localization of Force on a Capacitive Elastomeric Sensor Array Using Image Processing and Machine Learning

> 推荐日期：2026-08-14 | 来源：semantic_scholar | 引用数：6
> 推荐理由：该论文展示了在柔性电容传感器阵列上通过图像处理+ML实现毫秒级力点定位的完整pipeline，其"传感器数据→图像化→经典CV+ML"的路线对磁触觉阵列数据处理具有直接借鉴价值。

## 一句话核心贡献
将电容阵列数据转为图像，用Otsu阈值+连通域+聚类跟踪实现1ms内实时力点定位与跟踪。

## 与我们工作的关系
- **相同点**：目标一致——从触觉传感器阵列数据中实时估计接触位置和力大小；都采用"数据→特征→模型"的pipeline思路；都关注动态场景下的鲁棒性。
- **不同点**：① 传感原理不同——电容式 vs 磁触觉（霍尔效应）；② 方法路线不同——本文用图像处理（Otsu+CCL）+轻量ML做**稀疏力点检测**，而我们用MLP/CNN做**稠密位置/力回归**；③ 输出维度不同——本文输出离散力点坐标，我们输出连续力分布；④ 本文未涉及力大小回归的精度讨论，仅检测1-3N范围。
- **可借鉴的技术/思路**：① **数据图像化**：将传感器阵列读数映射为2D热图，可复用为CNN输入；② **Otsu自适应阈值**：用于磁触觉数据中区分"接触/非接触"区域，作为预处理步骤；③ **连通域+聚类跟踪**：多触点分离与跟踪策略，可迁移到磁触觉多指接触场景。
- **可在我们数据上验证的方法**：**部分可验证**。Otsu阈值+连通域方法可直接应用于我们2/4/6传感器demo的磁场数据，用于检测"哪些传感器区域被激活"；但本文的电容阵列是6×6=36通道，而我们单指仅4-6个磁传感器，空间分辨率差异大，聚类跟踪算法需大幅简化。
