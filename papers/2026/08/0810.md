# DIH-Tele: Dexterous In-Hand Teleoperation Framework for Learning Multiobjects Manipulation With Tactile Sensing

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：18
> 推荐理由：该工作展示了触觉感知在灵巧手多物体操作中的核心价值，其多模态融合与模仿学习思路对磁触觉感知驱动的灵巧操作任务具有直接参考意义。

## 一句话核心贡献
提出触觉灵巧手遥操作框架，结合多模态感知与模仿学习实现多物体计数操作。

## 与我们工作的关系
- **相同点**：均以触觉传感作为灵巧手操作的核心感知模态，强调触觉信息对精细操作行为的支撑作用；都涉及从触觉信号中提取可操作特征用于决策。
- **不同点**：该工作聚焦于**遥操作数据采集 + 模仿学习**的系统级框架，触觉主要用于多模态融合（视觉+触觉+本体感），而非直接用于**位置/力回归预测**；其触觉传感器类型与磁触觉原理不同，且未涉及MLP/CNN对触觉信号进行位置-力映射的建模路线。
- **可借鉴的技术/思路**：① 多模态数据同步采集与融合训练策略；② 离散控制空间设计，降低模仿学习难度；③ 遥操作系统的精度标定方法（人手-机械手映射）。
- **可在我们数据上验证的方法**：其**离散控制空间 + 融合训练**的模仿学习框架可迁移至我们的磁触觉demo，用于验证触觉特征（位置/力预测输出）在闭环操作任务中的有效性，但需先将我们的MLP/CNN预测结果接入其控制策略。

# ViTacFormer: Learning Cross-Modal Representation for Visuo-Tactile Dexterous Manipulation

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：47
> 推荐理由：该工作将视觉-触觉跨模态融合与自回归触觉预测结合，在灵巧手长时序操作任务上取得显著突破，其跨模态表征思路对磁触觉传感器数据融合策略具有直接参考价值。

## 一句话核心贡献
提出跨模态注意力融合视觉触觉并自回归预测未来触觉信号，提升多指手灵巧操作成功率50%。

## 与我们工作的关系
- **相同点**：均关注触觉信号在灵巧操作中的核心作用，且都采用学习-based方法从触觉数据中提取高维特征用于控制决策。
- **不同点**：ViTacFormer采用**跨模态注意力融合**（cross-attention）处理视觉+触觉双模态输入，并引入**自回归触觉预测头**预测未来接触信号；我们聚焦于**纯磁触觉**数据，用MLP/CNN回归**位置/力**，不涉及视觉模态与时序预测。
- **可借鉴的技术/思路**：① 自回归触觉预测头可迁移至我们的磁触觉时序数据，用于预测下一时刻接触力/位置变化；② 课程学习（curriculum learning）策略可优化我们模型在复杂接触场景下的训练稳定性；③ 跨模态注意力机制可启发我们探索多磁传感器间的关系建模。
- **可在我们数据上验证的方法**：自回归触觉预测头**适合**在2/4/6传感器demo上测试。我们的磁触觉数据天然是时序信号，可训练模型预测下一时刻的力/位置，增强动态操作中的前瞻性控制能力。

## 技术拆解

|------|------|
| 输入 | 高分辨率视觉图像 + 触觉传感器读数（多指手） |

| 关键创新 | ① 跨模态交叉注意力融合视觉-触觉表征；② 自回归触觉预测头实现前瞻性感知；③ 易到难课程学习策略逐步精炼潜在空间 |

# Super-resolution tactile sensor arrays with sparse units enabled by deep learning

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：70
> 推荐理由：以极少数物理传感器生成大量虚拟传感器，与磁触觉稀疏阵列实现高分辨率感知的目标高度契合，其自注意力SR框架对提升位置/力预测精度有直接借鉴价值。

## 一句话核心贡献
提出稀疏触觉阵列超分辨率框架，23个物理taxel生成2700个虚拟taxel，定位误差0.73mm。

## 与我们工作的关系
- **相同点**：均使用少量物理传感器（23个 vs 我们的2/4/6个）通过深度学习模型实现高分辨率触觉感知，输出包含接触位置信息，核心思路都是"小阵列+智能算法"。
- **不同点**：① 传感原理不同——他们用压阻式taxel，我们用磁触觉（磁场变化→位置/力）；② 模型架构不同——他们用自注意力辅助的超分辨率网络，我们采用MLP/CNN直接回归位置/力；③ 输出粒度不同——他们生成密集虚拟taxel压力分布图，我们直接输出离散接触位置和力值。
- **可借鉴的技术/思路**：① 拓扑优化策略——如何用最少的传感器位置覆盖最大感知区域，可直接用于我们磁传感器布局设计；② 自注意力机制——可引入我们的MLP/CNN pipeline中，增强对多接触点空间关系的建模能力；③ 虚拟taxel生成思路——可将稀疏磁信号映射为高分辨率触觉场，再从中提取位置/力。
- **可在我们数据上验证的方法**：适合。我们的2/4/6传感器demo与他们的"稀疏taxel"设定本质相同，可直接测试其SR框架是否能在磁触觉数据上生成高分辨率触觉场，再对比我们直接回归方法的精度差异。
