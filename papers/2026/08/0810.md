# Capacitive in-sensor tactile computing

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：38
> 推荐理由：该工作展示了在传感器阵列内部直接完成模拟乘加运算的"感内计算"范式，为磁触觉灵巧手在低功耗、低延迟场景下的片上处理提供了重要参考。

## 一句话核心贡献
提出电容式感内触觉计算系统，利用传感器网络原位执行模拟乘加运算，实现降噪与边缘检测。

## 与我们工作的关系
- **相同点**：两者都关注触觉传感器阵列的低层级信号处理（降噪、特征提取），且都涉及从原始传感数据到有用触觉信息的转换。
- **不同点**：该工作采用**电容式**传感器阵列，通过物理层面的模拟乘加实现"感内计算"，完全绕开ADC和数字处理器；我们的路线是**磁触觉**传感器 + MLP/CNN 数字模型预测位置/力，本质是"感后计算"，依赖传统数字信号链。
- **可借鉴的技术/思路**：其"传感器网络互联实现原位模拟运算"的思想可启发我们思考磁触觉阵列的模拟预处理方案（如利用磁传感器输出直接做差分/加权组合），减少后端MLP/CNN的输入维度或计算负担。
- **可在我们数据上验证的方法**：**不适合直接验证**。我们的磁触觉数据是离散的磁场矢量（3轴×N传感器），目标是回归位置/力连续值，而该方法是针对图像类压力分布的边缘检测/降噪任务。但可借鉴其"低功耗感内处理"思路，评估我们MLP/CNN模型在MCU上的功耗与延迟优化空间。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 电容式压力传感器阵列的原始电容变化量（模拟信号） |
| 输出 | 降噪后的触觉压力分布图、边缘检测结果（二值/灰度图） |
| 模型架构 | 无传统神经网络；利用传感器网络互联实现模拟乘法（权重）与累加（电流/电荷求和）运算，等效于固定权重的卷积/滤波操作 |
| 关键创新 | ① 感内计算（in-sensor computing）：传感与计算物理融合，消除传感-处理单元间的数据传输；② 模拟域乘加运算：利用电容阵列的物理特性直接完成矩阵运算；③ 低功耗：单次感算操作功耗较传统混合系统降低22倍以上 |

# Super-resolution tactile sensor arrays with sparse units enabled by deep learning

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：70
> 推荐理由：该工作用23个稀疏物理传感器生成2700个虚拟taxel，实现115倍超分辨率和0.73mm定位精度，为磁触觉稀疏阵列的"以小博大"提供了直接可借鉴的深度学习范式。

## 一句话核心贡献
提出自注意力辅助触觉超分辨框架，用23个稀疏物理taxel生成2700个虚拟taxel，实现115倍超分辨率和0.73mm定位精度。

## 与我们工作的关系
- **相同点**：均采用"稀疏物理传感器 + 深度学习模型"路线，通过数据驱动方式从少量传感器信号中恢复高分辨率触觉信息（位置/力分布），核心都是解决传感器数量与感知精度之间的矛盾。
- **不同点**：① 传感器模态不同——本文基于压阻/电容式taxel阵列，我们基于磁触觉（磁场-形变映射）；② 模型架构不同——本文采用**自注意力机制（self-attention）** 而非MLP/CNN，利用全局感受野捕捉空间相关性；③ 输出形式不同——本文输出**高分辨率压力分布图（虚拟taxel网格）** ，我们输出**接触位置/力标量**；④ 拓扑优化——本文还包含taxel布局的拓扑优化策略，我们目前未涉及传感器物理布局优化。
- **可借鉴的技术/思路**：① **自注意力模块**可嵌入我们现有的MLP/CNN pipeline中，增强多传感器信号间的空间关联建模能力；② **虚拟taxel生成策略**——我们可用2/4/6个磁传感器生成更高密度的虚拟"磁场-力"映射点，提升位置/力预测精度；③ **拓扑优化思想**——可启发我们优化磁传感器在指尖的物理布局。
- **可在我们数据上验证的方法**：**适合**。我们2/4/6传感器demo与本文23个物理taxel的稀疏设定高度一致，可直接将自注意力辅助超分辨框架迁移到磁触觉数据上，测试能否用少量磁传感器生成高密度虚拟触觉场，从而提升位置/力预测精度。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 23个稀疏物理taxel的压力信号（低分辨率触觉图） |

| 模型架构 | 自注意力辅助触觉超分辨模型（self-attention–assisted tactile SR），包含自注意力模块用于全局空间特征提取，结合CNN/Transformer混合结构 |
| 关键创新 | ① 通用拓扑优化策略用于taxel布局设计；② 自注意力机制实现全局空间相关性建模；③ 仅23个物理taxel生成2700个虚拟taxel，SR因子超115 |

# ViTacFormer: Learning Cross-Modal Representation for Visuo-Tactile Dexterous Manipulation

> 推荐日期：2026-08-10 | 来源：semantic_scholar | 引用数：47
> 推荐理由：跨模态Transformer融合视觉与触觉的SOTA方案，其自回归触觉预测头与课程学习策略对磁触觉感知-控制闭环设计极具参考价值。

## 一句话核心贡献
提出跨注意力编码器融合视觉触觉，并创新自回归触觉预测头与课程学习，实现长时序灵巧操作。

## 与我们工作的关系
- **相同点**：均以触觉传感为核心感知模态，服务于灵巧手精细操作任务；都涉及从原始触觉信号中提取高维特征用于下游控制决策。
- **不同点**：① 我们聚焦**磁触觉**的**位置/力预测**（几何-力学参数回归），ViTacFormer则直接学习**跨模态表征**用于策略学习，不显式解耦位置/力；② 我们采用MLP/CNN处理单模态时序信号，ViTacFormer用**Transformer跨注意力**融合视觉-触觉双模态；③ 我们面向传感器标定/感知层，ViTacFormer面向操作层（策略学习）。
- **可借鉴的技术/思路**：① **自回归触觉预测头**——可迁移至磁触觉时序预测（如预测下一时刻接触力/形变），增强感知的时序一致性；② **课程学习策略**——由易到难组织训练数据，可提升磁触觉模型在复杂接触场景下的鲁棒性；③ **跨模态注意力融合**——若未来引入视觉，可直接复用其融合架构。
- **可在我们数据上验证的方法**：**适合**。其自回归预测头可直接替换我们MLP/CNN的末端，在2/4/6传感器demo上验证时序预测能力；课程学习策略无需额外硬件，仅需重排训练样本顺序即可测试。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 高分辨率视觉图像（多视角）+ 高分辨率触觉图像（GelSight类传感器） |
| 输出 | 跨模态隐表征 → 策略动作（多指手关节角度）；辅助输出：未来触觉信号预测 |
| 模型架构 | 双流编码器（视觉/触觉各自独立编码）→ **Cross-Attention Encoder**（跨模态融合）→ 自回归触觉预测头（预测未来k步触觉）→ 策略头（模仿学习） |
| 关键创新 | ① 跨注意力融合视觉-触觉；② **自回归触觉预测头**（预测未来接触信号，隐式建模动力学）；③ **Easy-to-Challenging课程学习**（逐步增加任务难度，稳定优化隐空间） |

## 启发点
