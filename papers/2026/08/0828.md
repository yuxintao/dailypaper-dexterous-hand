# Shapeable planar Hall sensor with a stable sensitivity under concave and convex bending

> 推荐日期：2026-08-28 | 来源：arxiv | 引用数：0
> 推荐理由：展示了平面霍尔传感器在弯曲形变下灵敏度保持稳定的物理机制，为磁触觉灵巧手传感器在非平面安装场景下的可靠性提供了底层物理依据。

## 一句话核心贡献
首次证明平面霍尔传感器在凹凸弯曲下灵敏度稳定，可同时感知磁场与应力应变。

## 与我们工作的关系
- **相同点**：均基于平面霍尔/磁阻效应进行磁场感知，面向触觉传感应用场景，关注传感器在机械形变下的响应稳定性。
- **不同点**：该论文聚焦于**传感器物理层**（NiFe/IrMn 双层结构、Kapton/PDMS 柔性衬底）的弯曲稳定性验证，属于器件物理与材料工程范畴；我们的工作聚焦于**算法层**——利用 MLP/CNN 从多传感器 18D 磁场数据中回归接触位置与力，不涉及传感器本身的物理设计。
- **可借鉴的技术/思路**：论文揭示了 AMR 电压对应力敏感而平面霍尔电压对应力不敏感的物理特性。这提示我们在算法标定中，若传感器发生微小形变（如贴合曲面手指），**平面霍尔通道的标定参数漂移可能远小于 AMR 通道**，可据此设计分通道的鲁棒性策略或数据增强（对霍尔通道施加较小的噪声扰动）。
- **可在我们数据上验证的方法**：**不适合直接验证**。该论文无算法贡献，未提供任何数据处理或回归方法。其结论可作为我们传感器选型与安装方式的物理依据，但无法在我们的 2/4/6 传感器 demo 上运行任何代码。

## 技术拆解

|------|------|
| 输入 | 外部磁场（Oe 量级），传感器处于平面/凹面/凸面弯曲状态 |
| 输出 | 平面霍尔电压（灵敏度 0.74 μV/Oe·mA）与 AMR 电压 |

| 关键创新 | 首次观察到平面霍尔灵敏度在凹凸弯曲下保持稳定（线性区稳定、峰值位置不变），而 AMR 电压对应力敏感，实现单一器件多功能传感 |
| 训练数据规模 | 不适用（实验测量数据，无公开数据集） |
| 关键指标 | 磁场灵敏度 0.74 μV/Oe·mA；ON/OFF 重复实验稳定性；凹凸弯曲下灵敏度不变 |
| 开源代码 | 无 |
