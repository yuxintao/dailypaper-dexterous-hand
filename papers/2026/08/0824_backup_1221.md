# Rotating without Seeing: Towards In-hand Dexterity through Touch

> 推荐日期：2026-08-24 | 来源：semantic_scholar | 引用数：161
> 推荐理由：该工作证明了纯触觉（无视觉）即可完成灵巧手物体旋转任务，其全手覆盖式二值触觉设计对磁触觉传感器的布局与策略学习具有重要参考价值。

## 一句话核心贡献
提出仅用全手覆盖式二值触觉传感器实现无视觉灵巧手物体旋转的强化学习系统。

## 与我们工作的关系
- **相同点**：均以触觉为核心感知模态，不依赖视觉；均面临Sim2Real迁移问题；均涉及触觉信号到操作策略的映射学习。
- **不同点**：该工作使用**二值触觉（touch/no-touch）**，而我们使用**连续磁信号（18D磁场数据）**；该工作采用**RL端到端策略**，而我们走**MLP/CNN回归位置/力**路线；该工作传感器覆盖全手一侧，我们聚焦指尖/指腹局部区域。
- **可借鉴的技术/思路**：① 全手覆盖式传感器布局思想可启发我们在更多手指表面布置磁传感器；② 其Sim2Real中二值化触觉降低域差距的策略，可类比思考如何对磁信号做离散化/归一化以增强迁移性；③ 其RL训练框架（如域随机化、课程学习）可迁移到我们的位置/力预测任务中作为数据增强手段。
- **可在我们数据上验证的方法**：其核心结论"二值触觉足以完成灵巧操作"可在我们的2/4/6传感器demo上做消融验证——将18D磁场信号阈值化为二值信号，对比MLP/CNN在二值输入与连续输入下的位置/力预测精度，检验信息压缩的可行性。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 全手一侧覆盖的密集二值力传感器阵列（touch/no-touch），无视觉输入 |
| 输出 | 灵巧手关节角度动作（in-hand object rotation策略） |
| 模型架构 | 基于强化学习的策略网络（PPO），输入为二值触觉状态，输出关节动作；未见公开网络细节（CNN/MLP未明确） |
| 关键创新 | ① 全手覆盖式二值触觉设计（低成本、大覆盖、减小Sim2Real差距）；② 纯触觉无视觉的灵巧操作策略；③ 仿真训练直接部署到真实手且泛化到未见物体 |
| 训练数据规模 | 仿真中多种物体（未见具体数量），RL交互式采样；真实部署无需额外训练数据 |

## 启发点
- 二值触觉的"信息压缩"思路可启发我们探索磁信号的低比特量化是否仍能保持位置/力预测精度，从而降低传感器成本与计算负担。
- 全手覆盖式布局提示我们：磁传感器不应仅局限于指尖，在指节、手掌等位置布置可提供更全面的接触信息，可能提升操作稳定性。
