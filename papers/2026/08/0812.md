# AetheRock: An Arm-Worn Robot Teaching System for Force-Guided Vision-Tactile Learning

> 推荐日期：2026-08-12 | 来源：arxiv | 引用数：0
> 推荐理由：提出力引导的视觉-触觉表征学习框架，其"跨模态引导+保真度无关"思路对磁触觉位置/力预测的泛化问题有直接借鉴价值。

## 一句话核心贡献
提出臂戴式力-视觉-触觉采集系统及力引导的保真度无关触觉表征学习框架。

## 与我们工作的关系
- **相同点**：均关注触觉信号的表征学习与力/触觉信息解耦；ForceVT中"用易得模态（力/视觉）引导难标定模态（触觉）"的思路，与磁触觉中用磁场预测力/位置的目标一致——都是跨模态或跨任务的表征迁移。
- **不同点**：① 传感器模态不同——他们用GelSlim（视觉触觉）+电阻式压力传感器，我们用磁传感器（18D磁场数据）；② 核心问题不同——他们解决视触觉传感器制造不一致性（保真度差异），我们解决磁场-力/位置映射的非线性和多传感器融合；③ 学习范式不同——他们用对比/蒸馏式表征学习，我们目前以MLP/CNN直接回归为主。
- **可借鉴的技术/思路**：① **保真度无关（fidelity-agnostic）学习**——可类比为"传感器布局无关"或"传感器数量无关"的磁触觉表征，即训练一个对传感器个体差异鲁棒的编码器；② **力作为引导信号**——我们已有力标签，可借鉴其"力引导触觉学习"的框架，将力信号作为辅助监督或特征对齐目标；③ **模块化硬件设计思路**——虽然我们是算法团队，但其"易制造、模块化"的传感器设计理念可启发我们设计更易标定的磁传感器阵列。
- **可在我们数据上验证的方法**：**部分可验证**。ForceVT的"跨模态对齐/蒸馏"思想可迁移到我们的2/4/6传感器demo上——例如用高精度6传感器模型的输出作为"教师"，蒸馏到2/4传感器"学生"模型上，实现传感器数量无关的力/位置预测。但具体网络结构（如是否用Transformer）需根据我们的数据规模调整。

# TactX: Learning Shared Tactile Representations Across Diverse Sensors

> 推荐日期：2026-08-12 | 来源：arxiv | 引用数：0
> 推荐理由：提出跨电阻/磁/视觉三种模态的共享触觉表征框架，为磁触觉灵巧手摆脱传感器特异性、实现跨硬件迁移提供了新思路。

## 一句话核心贡献
跨三种触觉模态学习共享表征，实现策略零样本跨传感器迁移。

## 与我们工作的关系
- **相同点**：均以触觉数据为输入，通过神经网络（编码器/MLP）提取高维特征用于下游任务（分类/策略），且都涉及磁传感器数据。
- **不同点**：我们聚焦单模态（磁）下的位置/力回归，TactX 关注多模态对齐与共享表征学习，输出为传感器无关的 latent code 而非物理量；其训练依赖跨模态配对数据，我们则依赖真值标签。
- **可借鉴的技术/思路**：① 模态对齐的对比/重建损失设计，可用于我们多传感器（2/4/6）间的特征一致性约束；② 传感器身份预测作为表征质量评估指标，可迁移到我们多传感器布局的标定与一致性验证；③ 共享编码器+任务头的架构，可启发我们将位置/力预测与传感器无关表征解耦。
- **可在我们数据上验证的方法**：部分可验证。我们有多传感器（2/4/6）的 18D 磁场数据，可仿照其"配对数据对齐"思路，用同一物体同一接触点的多传感器读数构造配对样本，训练共享编码器并评估传感器身份预测准确率。但需注意我们无跨模态（视觉/电阻）数据，仅能验证同模态多传感器间的对齐。

## 技术拆解

|------|------|
| 输入 | 三种模态的触觉观测：电阻式（如 GelSight 类）、磁式（如磁触觉传感器）、视觉式（相机图像） |
| 输出 | 共享 latent space 中的触觉表征向量（sensor-agnostic embedding） |
| 模型架构 | 模态特定编码器（modality-specific encoders）→ 共享 latent space；编码器联合训练，配对接触数据提供对齐信号 |
