# AetheRock: An Arm-Worn Robot Teaching System for Force-Guided Vision-Tactile Learning

> 推荐日期：2026-08-12 | 来源：arxiv | 引用数：0
> 推荐理由：提出力引导的视觉-触觉表征学习框架，其"跨模态引导+保真度无关"思路对磁触觉位置/力预测的泛化问题有直接借鉴价值。

## 一句话核心贡献
提出臂戴式力-视觉-触觉采集系统及力引导的保真度无关触觉表征学习框架。

## 与我们工作的关系
- **相同点**：均关注触觉信号的表征学习与力/触觉信息解耦；ForceVT中"用易得模态（力/视觉）引导难标定模态（触觉）"的思路，与磁触觉中用磁场预测力/位置的目标一致——都是跨模态或跨任务的表征迁移。
- **不同点**：① 传感器模态不同——他们用GelSlim（视觉触觉）+电阻式压力传感器，我们用磁传感器（18D磁场数据）；② 核心问题不同——他们解决视触觉传感器制造不一致性（保真度差异），我们解决磁场-力/位置映射的非线性和多传感器融合；③ 学习范式不同——他们用对比/蒸馏式表征学习，我们目前以MLP/CNN直接回归为主。
- **可借鉴的技术/思路**：① **fidelity-agnostic 的问题意识**——它解决的问题（"同一物理输入在不同传感器上读出不同信号"）对我们**真实且更尖锐**：磁触觉的位置预测依赖通道比例结构，而 X/S 归一化只对"整体缩放"免疫，对"逐通道/几何装配漂移"不免疫；② **Tactile Random Masking**（训练时随机遮空间 patch 防止过拟合）从反面印证我们 A1 实验的"稀疏性下界"结论——随机遮断正则化只在有冗余的密集阵列有效；③ 其对齐框架依赖跨模态锚点（视觉+力），我们是单模态磁触觉，**无法直接迁移**。
- **可在我们数据上验证的方法**：**不直接迁移其方法，但可做"传感器漂移敏感性诊断实验"**（详见算法文档 A5）——纯数据层、fitrnet 内，对 B 场做三类增广（乘性整体缩放 / 逐通道缩放 / 几何漂移），量化模型对三类漂移的退化，回答"换批次/重新装配要不要重新训练"。

1. **fidelity 问题意识比方法本身更值钱**：它揭示"模型对传感器物理漂移的鲁棒性"是触觉学习的通用问题。磁触觉更尖锐——位置预测依赖通道比例结构，X/S 归一化只对整体缩放（剩磁批次漂移）免疫，对逐通道（霍尔批次）和几何装配漂移不免疫。

# TactX: Learning Shared Tactile Representations Across Diverse Sensors

> 推荐日期：2026-08-12 | 来源：arxiv | 引用数：0
> 推荐理由：提出跨电阻/磁/视觉三种模态的共享触觉表征框架，为磁触觉灵巧手摆脱传感器特异性、实现跨硬件迁移提供了新思路。

## 一句话核心贡献
跨三种触觉模态学习共享表征，实现策略零样本跨传感器迁移。

## 与我们工作的关系
- **相同点**：均以触觉数据为输入，通过神经网络（编码器/MLP）提取高维特征用于下游任务（分类/策略）。**关键：其磁式传感器 eFlesh 与我们同属"磁铁+霍尔测磁场变化"家族**，且被论文形容为"lower-dimensional"（低维），是三个传感器里最接近我们 2/4/6 路磁触觉的一个。
- **不同点**：我们聚焦单模态（磁）下的位置/力回归，TactX 关注多模态对齐与共享表征学习，输出为传感器无关的 latent code 而非物理量；其训练依赖跨模态配对数据（电阻+磁+视觉两两配对），我们则是单模态、无跨模态锚点。
- **可借鉴的技术/思路**：① **传感器身份预测（identity probe）**——训练一个分类器预测"样本来自哪个传感器"，越低越好，且**必须与"接触信息仍在"（物体分类/回归不退化）配对看**，否则被 trivial 退化解骗过；这是可落地的方法论，不是空想；② **传递性对齐**——模型从没见过三传感器同接触，仅靠两两配对就做到三向对齐（D–F cosine 0.928），证明对齐关系可传递；③ **不对称性结论**——eFlesh（低维磁式）→ FlexiTac（高维电阻式）迁移最弱，反过来更强，直接支持"信息量增减对可迁移性不对称"的判断。
- **可在我们数据上验证的方法**：**身份探针可直接用**——它对我们是"力值档位分类器"而非"传感器身份分类器"，用来验证 X/S 解耦是否干净（详见算法文档"解耦验证方法补充"）。但 TactX 的跨模态对齐框架本身需要电阻/视觉锚点，我们是单模态，**不能照搬**。
