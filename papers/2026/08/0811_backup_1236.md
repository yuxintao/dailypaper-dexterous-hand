# Capacitive in-sensor tactile computing

> 推荐日期：2026-08-11 | 来源：semantic_scholar | 引用数：38
> 推荐理由：提出传感器内模拟计算范式，将传感与计算融合，为灵巧手触觉系统低功耗实时处理提供新思路，值得对比参考。

## 一句话核心贡献
提出柔性电容压力传感器阵列内原位模拟乘加计算，实现低功耗触觉感知与计算融合。

## 与我们工作的关系
- **相同点**：均面向触觉传感阵列的实时信息处理，关注从原始触觉信号中提取有效特征（如边缘、噪声滤除），服务于物体操作等下游任务。
- **不同点**：本工作采用**电容式**传感器阵列，通过**传感器互连网络**在模拟域直接完成乘加运算（in-sensor computing），无需显式ADC转换和数字处理器；我们采用**磁触觉**方案，通过MLP/CNN等**数字神经网络**从磁场信号回归位置/力，传感与计算在物理上分离，依赖数字后端。
- **可借鉴的技术/思路**：① 传感器阵列互连实现模拟乘加的架构思想，可用于磁触觉阵列的模拟前端预处理（如差分磁场信号的模拟加权）；② 低功耗设计理念，可评估我们数字pipeline的功耗瓶颈；③ 噪声抑制与边缘检测作为低层触觉处理任务的benchmark思路。
- **可在我们数据上验证的方法**：边缘检测和噪声滤除任务可直接迁移到我们的2/4/6传感器demo上——将磁传感器阵列的磁场分布视为"图像"，用其方法思想做空间滤波对比MLP/CNN的预处理效果。但需注意其模拟计算依赖特定电容硬件，我们只能在数字域模拟其算法效果，硬件层面[信息不足]。

# A Flexible Hall Effect-Based Tactile Sensor With a Halbach Array

> 推荐日期：2026-08-11 | 来源：semantic_scholar | 引用数：0
> 推荐理由：提出Halbach阵列磁化方案实现法向/剪切力自解耦，为磁触觉传感器结构设计提供了新思路，值得关注。

## 一句话核心贡献
提出Halbach阵列磁化弹性薄膜的柔性磁触觉传感器，实现法向与剪切力自解耦，无需复杂算法。

## 与我们工作的关系
- **相同点**：均基于磁原理进行触觉感知，目标都是通过磁场变化反演接触力/位置信息，且都关注法向力与剪切力的解耦问题。
- **不同点**：本文采用**Halbach阵列磁化**的物理结构实现自解耦，**无需神经网络**（MLP/CNN）进行力/位置预测，而是通过磁场分布与力的理论映射直接标定；我们则依赖数据驱动模型从磁场信号中回归力/位置。
- **可借鉴的技术/思路**：Halbach阵列的磁化布局设计可增强磁场梯度，提高信噪比，该思路可迁移至我们传感器的磁体排布优化；其弹性体参数调节量程/灵敏度的标定方法也值得参考。
- **可在我们数据上验证的方法**：可以。将Halbach阵列磁化方案应用于我们的2/4/6传感器demo中，对比现有磁体排布下的MLP/CNN预测精度，验证物理结构优化是否能降低对模型复杂度的依赖。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 霍尔传感器阵列采集的磁场强度（Bx, By, Bz） |
| 输出 | 法向力（0–15 N）、剪切力（0–5 N） |
| 模型架构 | 无学习模型，基于Halbach阵列磁场分布与力的理论映射直接标定 |
| 关键创新 | ①Halbach阵列磁化实现法向/剪切力自解耦；②柔性结构设计；③弹性体参数可调量程与灵敏度 |
| 训练数据规模 | 不适用（无监督学习，基于标定实验） |
| 关键指标 | 法向力线性拟合误差3.27%（0–15 N）；剪切力拟合误差3.52%（0–5 N） |

| 计算需求 | 极低（无需GPU，纯标定计算） |

## 启发点
- 物理结构层面的自解耦设计可大幅降低对复杂解耦算法的依赖，我们可探索在传感器端引入类似磁场布局优化，减少MLP/CNN的拟合负担。

# Design and Fabrication of a Piezoresistive Tactile Sensor Inspired by Human Skin Microstructure for Robotic Manipulation
