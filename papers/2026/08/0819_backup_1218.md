# Multifingered force-aware control for humanoid robots

> 推荐日期：2026-08-19 | 来源：arxiv | 引用数：0
> 推荐理由：该论文展示了基于Xela磁触觉传感器的力估计在全身力感知控制中的实际应用，与我们的磁触觉+MLP力预测路线高度相关，且提供了完整开源代码，值得深入拆解。

## 一句话核心贡献
提出基于磁触觉力估计的全身力感知控制框架，通过最小化压力中心与指尖接触多边形质心距离实现稳定抓取。

## 与我们工作的关系
- **相同点**：同样使用Xela磁触觉传感器，通过MLP类模型从磁场信号回归力/压力分布，与我们的磁触觉+MLP/CNN位置-力预测路线在传感器前端和力估计模块上高度一致。
- **不同点**：我们聚焦于单点/局部位置-力预测精度提升，而该论文将力估计作为中间表征，服务于全身运动控制（torso/arm/wrist/finger协同），核心贡献在控制层而非感知层。
- **可借鉴的技术/思路**：① 力估计器的训练pipeline（数据集采集+ground-truth标定流程）；② 将估计力而非原始磁场信号作为控制输入的"感知-控制解耦"思想；③ CoP与接触多边形质心距离最小化的控制目标设计。
- **可在我们数据上验证的方法**：其力估计器训练流程可直接迁移到我们的2/4/6传感器demo上，但控制层验证需要完整机器人平台，超出我们当前仿真/硬件能力。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 5个Xela磁触觉传感器的磁场信号（原始tactile signals） |
| 输出 | 每个传感器的力估计值 → 用于计算CoP和接触多边形质心 |
| 模型架构 | 力估计器（具体架构未详述，推测为MLP类回归模型）+ 模型预测控制器（MPC类） |
| 关键创新 | ① 力感知控制框架：将估计力作为控制输入，实现全身协同；② CoP-接触多边形质心距离最小化策略，适应质量分布变化和不稳定接触；③ 传感器无关性：基于力而非原始信号，可迁移至任意力估计传感器 |
| 训练数据规模 | 使用5个Xela传感器与indenters交互采集，具体样本量未披露 |
| 关键指标 | 单物体平衡任务成功率82.7%；多物体场景准确率80% |
| 开源代码 | ✅ https://github.com/hsp-iit/multifingered-force-aware-control |
| 计算需求 | 力估计器为轻量级MLP，控制为MPC，单GPU或纯CPU可运行 |

# Mechanisms and Computational Design of Multi-Modal End-Effector with Force Sensing using Gated Networks

> 推荐日期：2026-08-19 | 来源：arxiv | 引用数：0
> 推荐理由：提出基于霍尔传感器的8轴力感知机制与计算设计框架，其gated network多模态融合思路对磁触觉灵巧手的力/位解耦预测有直接参考价值。

## 一句话核心贡献
提出霍尔磁传感8轴力感知机制及含噪声抑制的计算设计框架，用gated network实现多模态足-爪末端力觉预测。

## 与我们工作的关系
- **相同点**：均采用**霍尔效应磁传感器**进行力/触觉感知；均需处理**磁场-力映射**的非线性逆模型问题；均涉及**多传感器融合**与**噪声/干扰抑制**。
- **不同点**：MAGPIE面向足式机器人足-爪双模态末端，输出为**8轴力/力矩**；我们面向灵巧手，输出为**接触位置+力**。MAGPIE采用**gated network**（门控融合多模态特征），我们采用**MLP/CNN直接回归**；MAGPIE强调**传感器布局的数学优化**（计算设计框架），我们更关注**数据驱动端到端预测**。
- **可借鉴的技术/思路**：① **计算设计框架**——在传感器布局阶段即考虑噪声与干扰，生成理想逆模型，可作为我们传感器排布的数学优化参考；② **Gated network融合策略**——用门控机制自适应融合不同传感模态（如磁+电机电流），提升力预测鲁棒性；③ **理想模型+学习残差**的两阶段思路，可加速训练收敛。
- **可在我们数据上验证的方法**：**Gated network融合**可直接迁移——将我们4/6传感器的18D磁场数据作为输入，用门控网络融合不同传感器组特征，对比MLP基线。**计算设计框架**需适配，因为我们传感器布局已固定，但可用于评估现有布局的噪声敏感度。

# UniForce: A Unified Latent Force Model for Robot Manipulation with Diverse Tactile Sensors

> 推荐日期：2026-08-19 | 来源：arxiv | 引用数：0
> 推荐理由：提出跨传感器统一触觉力表征框架，通过正/逆动力学联合建模实现零样本迁移，为磁触觉传感器与其他模态（光学等）的力感知对齐提供了全新思路。

## 一句话核心贡献
提出跨异构触觉传感器的统一隐式力表征框架，通过正逆动力学联合建模实现零样本力感知迁移。

## 与我们工作的关系
- **相同点**：均以接触力为预测目标，且都关注从原始触觉信号（图像/磁场）回归力信息，属于数据驱动的力感知回归任务。
- **不同点**：我们聚焦单一磁触觉模态下的位置/力预测（MLP/CNN直接回归），而UniForce解决的是**跨传感器模态**的力表征统一问题，核心是消除光学与磁触觉之间的域差异，而非提升单模态预测精度。
- **可借鉴的技术/思路**：① 正动力学（force-to-image）与逆动力学（image-to-force）联合训练的闭环约束思想，可用于我们磁触觉数据的自监督预训练；② 静态平衡约束生成力配对数据的方法，可减少对外部F/T传感器的依赖；③ 共享隐式力空间的设计，未来可扩展至多指协同的跨指力对齐。
- **可在我们数据上验证的方法**：部分可验证。我们2/4/6传感器demo的18D磁场数据可类比为"图像"输入，若将MLP/CNN替换为UniForce的编码器-解码器结构，并引入力重构损失，可测试其是否提升力预测精度。但跨模态对齐部分需要额外传感器数据，[信息不足]无法直接验证。
