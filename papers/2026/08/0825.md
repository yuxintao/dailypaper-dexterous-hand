# Closing the Reality Gap: Zero-Shot Sim-to-Real Deployment for Dexterous Force-Based Grasping and Manipulation

> 推荐日期：2026-08-25 | 来源：arxiv | 引用数：0
> 推荐理由：该论文提出了一套完整的sim-to-real强化学习框架，其密集触觉仿真与电流-力矩标定方法对磁触觉灵巧手的力控策略训练具有直接借鉴价值。

## 一句话核心贡献
提出零样本sim-to-real强化学习方法，用密集触觉+电流标定实现五指手力控抓取。

## 与我们工作的关系
- **相同点**：都依赖触觉传感信号作为力控反馈，都面临真实硬件部署时传感器读数与仿真不一致的域差问题。
- **不同点**：该论文使用**虚拟密集触觉单元**（点云距离计算）而非磁传感器阵列，且采用**强化学习**端到端学习策略，而非我们基于MLP/CNN的**监督式位置-力回归**；其触觉信号为二值/距离量，而我们输出连续6D力/力矩向量。
- **可借鉴的技术/思路**：① **电流-力矩标定**方法——我们可用电机电流估计关节力矩，辅助磁触觉力预测做交叉验证；② **触觉仿真加速**思路——用并行前向运动学计算虚拟触觉单元与物体距离，可类比为磁触觉仿真中快速计算磁体-传感器相对位姿；③ **非理想执行器动力学建模+随机化**——可用于我们数据采集中电机迟滞/摩擦的域随机化增强。

# Current as Touch: Proprioceptive Contact Feedback for Compliant Dexterous Manipulation

> 推荐日期：2026-08-25 | 来源：arxiv | 引用数：0
> 推荐理由：提出用电机电流作为本体感受触觉信号预测柔顺参考位置，为无额外触觉传感器的灵巧手力控提供新范式，与磁触觉的"信号→力/位置"预测路线高度互补。

## 一句话核心贡献
用电机电流预测PD控制器柔顺参考位置，实现无外部触觉传感器的灵巧手接触力自适应。

## 与我们工作的关系
- **相同点**：两者都从原始传感信号（电机电流 vs 磁场）直接预测接触相关的物理量（参考位置 vs 力/位置），均采用学习式方法（MLP/CNN类）建立映射，且目标都是为灵巧手提供接触反馈。
- **不同点**：磁触觉直接测量接触形变引起的磁场变化，物理信号更直接；电机电流是间接的力代理信号，信噪比低且受重力、摩擦、动力学耦合干扰大。此外，该工作输出的是"参考位置"而非力/位置本身，通过PD控制器隐式产生力，而我们的路线直接回归力/位置。
- **可借鉴的技术/思路**：①"预测参考位置而非直接预测力"的间接控制范式，可缓解力回归的噪声敏感问题；②利用PD控制器位置误差作为隐式力反馈的闭环思路；③电流信号与关节状态的融合方式。
- **可在我们数据上验证的方法**：部分可验证。可将我们的磁场特征替换其电流特征，输出改为"参考位置偏移"而非直接力值，在2/4/6传感器demo上对比直接力回归与参考位置回归的精度差异。但需注意磁场信号与电流信号的物理特性差异较大，需重新设计网络输入。

# SARL: Spatially-Aware Self-Supervised Representation Learning for Visuo-Tactile Perception

> 推荐日期：2026-08-25 | 来源：arxiv | 引用数：0
> 推荐理由：提出空间感知的自监督表征学习方法，通过保留特征图空间结构显著提升视觉-触觉融合感知的几何敏感任务表现，为磁触觉数据表征学习提供新思路。

## 一句话核心贡献
提出空间感知自监督框架SARL，用三个图级损失保留特征空间结构，提升视觉-触觉融合表征质量。

## 与我们工作的关系
- **相同点**：均关注触觉感知中的几何/位置信息编码，都使用CNN类骨干网络提取特征，都面临"全局特征丢失局部空间细节"的问题。
- **不同点**：SARL针对视觉-触觉融合图像（如GelSight）设计，输入为单张融合图像，输出为下游任务通用表征；我们使用18D磁场时序数据，输入为多传感器磁信号，输出为位置/力预测，且我们通常用MLP/轻量CNN直接回归，不做预训练表征学习。
- **可借鉴的技术/思路**：① **Saliency Alignment (SAL)**：用注意力图一致性约束增强关键接触区域的特征响应，可迁移到磁触觉中"接触点附近传感器权重更大"的先验；② **Patch-Prototype Distribution Alignment (PPDA)**：将特征图划分为patch并与原型对齐，可类比为对4个传感器各自提取局部特征再对齐；③ **Region Affinity Matching (RAM)**：保持区域间几何关系一致，可启发我们在多传感器布局中显式建模传感器间空间关系。
- **可在我们数据上验证的方法**：部分可验证。SAL和RAM的思想可迁移到我们的多传感器设置中——将每个传感器的特征图视为一个"patch/region"，用对比或一致性损失约束传感器间特征关系。但PPDA依赖原型聚类，需要较大数据量，在单demo上可能不稳定。整体上需要将"视图间一致性"改为"传感器间一致性"，属于中等程度的适配工作。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | 视觉-触觉融合图像（单张，如GelSight输出），分辨率未明确给出 |
| 输出 | 空间感知的视觉-触觉表征（用于下游任务微调） |
| 模型架构 | 基于BYOL的SSL框架，在中间特征图上附加三个图级损失头：SAL（注意力对齐）、PPDA（patch-原型分布对齐）、RAM（区域亲和匹配） |
| 关键创新 | ① 首次在视觉-触觉SSL中显式保留空间结构；② 三个图级损失互补：注意力（SAL）+ 部件组成（PPDA）+ 几何关系（RAM）；③ 与全局BYOL损失联合优化，兼顾全局与局部 |
| 训练数据规模 | [信息不足] 摘要未提及具体数据量，仅提及在6个下游任务上评估 |
| 关键指标 | 在6个下游任务上一致优于9个SSL基线，尤其在几何敏感任务上提升显著（具体数值未给出） |
| 开源代码 | [信息不足] 未提及 |
| 计算需求 | [信息不足] 未提及，但BYOL类方法通常需要较大batch size（如256-512），单GPU训练可能较慢 |

## 启发点
- **传感器间一致性正则化**：将SAL/RAM思想迁移到多磁传感器设置，用一致性损失约束不同传感器对同一接触事件的特征响应，可能提升位置预测的鲁棒性。
