# DexTOG: Learning Task-Oriented Dexterous Grasp With Language Condition

> 推荐日期：2026-08-20 | 来源：semantic_scholar | 引用数：15
> 推荐理由：语言引导的扩散模型用于灵巧手任务导向抓取，其多解抓取生成思路可为磁触觉多传感器数据融合提供新视角。

## 一句话核心贡献
提出语言引导扩散模型DexDiffu及数据引擎，生成灵巧手任务导向抓取姿态，并构建DexTOG-80K数据集。

## 与我们工作的关系
- **相同点**：均面向灵巧手操作任务，需要处理高维传感/控制信号，且都关注多传感器信息融合与任务约束下的决策问题。
- **不同点**：DexTOG是**纯视觉+语言**驱动的抓取姿态生成（无触觉反馈），输出为关节角度/抓取位姿；我们则是**磁触觉驱动**的接触位置/力预测（MLP/CNN回归），输出为物理接触状态。两者在感知模态、输出空间和网络范式（扩散生成 vs 判别回归）上本质不同。
- **可借鉴的技术/思路**：扩散模型处理"多解"问题的能力——灵巧手抓取存在多个可行解，与我们多传感器位置/力预测中可能存在的多模态映射（不同接触模式对应相似磁场）有类比性；其语言条件注入方式也可迁移为"任务/物体类别"条件注入到我们的预测网络中。
- **可在我们数据上验证的方法**：**[信息不足]** 论文未提供开源代码，且其输入为视觉+语言，与我们的18D磁场数据无直接映射关系。但扩散模型作为多解生成框架的思路，可在我们2/4/6传感器demo上以"条件扩散预测接触位置分布"的形式验证，需要较大的改造工作。

# Soft Object Dexterous Manipulation Using Deep Reinforcement Learning

> 推荐日期：2026-08-20 | 来源：semantic_scholar | 引用数：1
> 推荐理由：该论文展示了DRL在软物体抓取中的力控策略，其"位置+力"联合优化目标与磁触觉灵巧手的位置/力预测任务高度契合，值得关注其奖励函数设计思路。

## 一句话核心贡献
用SAC和PPO在PyBullet中训练机器人抓取软物体，实现精确位置与不损伤的力度控制。

## 与我们工作的关系
- **相同点**：目标都是实现对物体的"位置+力"联合控制；都关注软物体交互中的力感知与力控制问题。
- **不同点**：该论文使用**仿真环境（PyBullet）+ 强化学习（SAC/PPO）**，不依赖物理触觉传感器；我们使用**真实磁触觉传感器 + MLP/CNN 监督学习**直接回归位置/力。前者是"感知-动作"闭环策略学习，后者是"感知-状态"回归建模。
- **可借鉴的技术/思路**：奖励函数设计（位置误差+力损伤惩罚的加权组合）可作为我们力预测模型训练损失函数的参考；SAC的熵正则化思想可启发我们在小样本磁场数据上训练时的探索策略。
- **可在我们数据上验证的方法**：**暂不适合直接验证**。该方法是端到端RL策略，需要完整的仿真环境和机器人闭环，而我们的demo是传感器数据回归任务，两者问题设定不同。但奖励函数中的"力损伤惩罚"思想可迁移到我们的损失函数设计中（如对预测力超阈值施加额外惩罚）。
