# Beyond Binary: Sim-to-Real Dexterous Manipulation with Physics-Grounded Contact Representation

> 推荐日期：2026-08-26 | 来源：arxiv | 引用数：0
> 推荐理由：提出基于物理原理的CoP触觉表征替代离散接触信号，为磁触觉连续力/位置预测的sim-to-real迁移提供了全新思路。

## 一句话核心贡献
提出基于物理的压力中心(CoP)触觉表征及可微动力学标定方案，实现零样本sim-to-real灵巧操作。

## 与我们工作的关系
- **相同点**：均关注触觉信号的连续、稠密表征（而非二值接触），且都涉及从原始触觉阵列到物理量（力/位置）的回归预测问题。
- **不同点**：我们采用磁触觉（18D磁场数据经MLP/CNN回归力与位置），而本文采用压阻式taxel阵列，通过物理公式直接计算CoP，不依赖学习网络进行表征提取；其标定依赖可微动力学而非真值力传感器。
- **可借鉴的技术/思路**：① CoP作为中间表征的降维思想——可将18D磁场数据先回归为接触力分布，再计算CoP作为策略输入，降低sim-to-real gap；② 基于可微动力学的标定方案——无需真值力传感器即可估计taxel朝向，可类比用于磁传感器安装姿态的自标定。
- **可在我们数据上验证的方法**：适合。可在2/4/6传感器demo上，将MLP预测的接触力转换为CoP坐标作为策略输入，对比直接使用原始18D磁场或预测力值的策略性能，验证CoP表征在磁触觉路线上的有效性。

# Tactile Sim2Real without Tactile Simulation via Bottlenecked Latent Reconstruction

> 推荐日期：2026-08-26 | 来源：arxiv | 引用数：0
> 推荐理由：提出一种完全绕过触觉传感器仿真的Sim2Real新范式，用Oracle传感器潜空间对齐替代物理仿真，对磁触觉这类难以精确建模的传感器极具参考价值。

## 一句话核心贡献
提出免触觉仿真的Sim2Real框架，用Oracle传感器潜空间对齐替代物理仿真，解决真实触觉传感器域差异问题。

## 与我们工作的关系
- **相同点**：都关注触觉传感器信号的表征学习与域适应问题，都需要将传感器原始信号映射到可用的任务表征空间。
- **不同点**：我们聚焦磁触觉的位置/力回归预测，属于**传感器信号→物理量**的直接映射；本文聚焦**策略学习**的Sim2Real，属于**传感器信号→任务策略**的端到端对齐，且完全绕开传感器物理建模。
- **可借鉴的技术/思路**：**Bottlenecked Latent Reconstruction**思想——通过瓶颈层强制提取与任务相关的核心特征，可迁移到我们的磁触觉位置/力预测中，用于滤除磁场噪声和温度漂移等无关干扰；**Rectified-flow变换网络**用于跨域对齐的思路，可借鉴到磁触觉传感器间的迁移（如2传感器→4传感器）。
- **可在我们数据上验证的方法**：部分可验证。Bottleneck架构可直接替换我们MLP/CNN的中间层，观察位置/力预测精度是否提升；但Oracle传感器对齐需要仿真环境，我们目前无仿真数据，需构造伪Oracle（如高密度传感器数据作为低密度的Oracle）。

## 技术拆解
| 维度 | 内容 |
|------|------|
| 输入 | Oracle传感器（点云+指尖力）的潜空间表征；真实触觉传感器的原始信号 |
| 输出 | 策略动作（接触丰富任务）；对齐后的真实传感器潜空间表征 |
| 模型架构 | 两阶段：①策略网络学习Oracle传感器潜空间→动作映射；②Bottlenecked Latent Reconstruction网络将真实传感器表征对齐到Oracle潜空间（含瓶颈层强制信息压缩）；③Rectified-flow变换网络基于最近邻伪配对学习跨域映射 |
| 关键创新 | ①完全绕开触觉传感器物理仿真；②用Oracle传感器（易构建）替代精确传感器建模；③无配对数据下的跨域对齐（unpaired random-play + nearest-neighbor pseudo-pairs）；④Bottleneck层模拟真实传感器的信息损失 |
| 训练数据规模 | 仿真中Oracle传感器的random-play数据 + 真实传感器的random-play数据（无配对要求）；三个接触丰富任务 |
| 关键指标 | 与SBLR匹配的基线对比（摘要截断，具体数值[信息不足]） |
| 开源代码 | [信息不足]（未提及） |
| 计算需求 | [信息不足]（未提及，但Rectified-flow训练通常需GPU） |

## 启发点
- **Bottleneck层设计**：在磁触觉MLP/CNN中引入瓶颈层，强制模型只保留与位置/力预测最相关的磁场特征，可能天然抑制温度漂移和传感器串扰。

# Feel Robot Feels: Tactile Feedback Array Glove for Dexterous Manipulation

> 推荐日期：2026-08-26 | 来源：arxiv | 引用数：0
> 推荐理由：该工作将磁传感用于手部运动捕捉并与触觉反馈阵列结合，其磁传感硬件思路与我们的磁触觉路线同源，但聚焦于遥操作人机交互而非接触力预测，值得作为系统级参考。

## 一句话核心贡献
提出低成本触觉反馈手套TAG，集成21自由度磁运动捕捉与指尖32单元触觉阵列，实现触觉闭环灵巧遥操作。

## 与我们工作的关系
- **相同点**：均采用**非接触磁传感**方案，利用磁场信息进行高精度状态估计（他们估计关节角，我们估计接触位置/力）；均面向灵巧操作场景。
- **不同点**：① 他们的磁传感用于**运动捕捉**（关节角度），我们用于**接触感知**（位置/力预测）；② 他们的核心贡献在**硬件系统集成**与人机交互反馈回路，**无机器学习模型**；我们的核心在**MLP/CNN数据驱动预测**；③ 他们的输出是21-DoF关节角（回归），我们输出是接触位置/力（回归/分类）。
- **可借鉴的技术/思路**：① 磁传感的**抗电磁干扰设计**与标定流程，可用于提升我们传感器在电机干扰下的鲁棒性；② **32单元触觉阵列的空间激活模式**编码方式，可启发我们将4/6传感器稀疏输出映射为空间模式；③ 遥操作数据采集框架，可用于构建我们的接触力标签采集系统。
