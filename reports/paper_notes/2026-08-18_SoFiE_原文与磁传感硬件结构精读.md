> 论文：*SoFiE: Soft Finger Exoskeleton for Intelligent Grasping*

> 版本：arXiv:2606.00397v1，2026-05-29

## 1. 阅读结论先行

SoFiE是一套辅助食指弯曲的轻量、无线软体外骨骼。论文的核心不是学习算法，而是把三种不同层级的状态信息整合到一条机械传动链中：

```text
电机编码器                    StretchSense                    MagSense
驱动端位移          →         外骨骼/手指形变        →        指尖接触与局部压缩
motor state                   body state                      contact state
```

MagSense与我们的磁触觉原理同源：软介质受压后，永磁体相对三轴磁力计发生位移，磁场随距离与方向改变。但该论文只完成了接触响应和不同泡棉顺应性的区分，未完成绝对力、绝对刚度、接触位置或剪切力标定。

## 2. 整机由哪些硬件结构组成

### 2.1 多材料打印的外骨骼骨架

| 项目 | 原文配置 | 作用 |
|---|---|---|
| 主体材料 | ColorFabb VarioShore TPU | 形成可穿戴的柔性手指模块 |
| 制造方式 | 多材料/局部性能调节的FDM 3D打印 | 通过打印温度改变局部机械性能 |
| 刚性区域 | 三个指骨环：J1、J2、J3 | 分别连接远端、中段和近端指骨 |
| 柔性区域 | 软质、多孔基底 | 贴合手部并吸收小幅制造公差 |
| 模块连接 | 开口C形环、snap-fit连接 | 便于按手型调整、替换和维修 |

原文没有给出打印温度与对应模量，因此“局部刚度可调”已经展示为制造思路，但尚不是可直接复刻的完整工艺参数表。

### 2.2 腱绳驱动结构

| 项目 | 原文配置 | 作用 |
|---|---|---|
| 电机 | Pololu 6 V Micro Metal Gearmotor，250:1 | 驱动食指屈曲 |
| 位置反馈 | 电机集成编码器 | 测量驱动端位移，并设置软件运动限位 |
| 腱绳 | 3股不锈钢绳 | 沿掌侧穿过指环，在远端折返至电机卷轴 |
| 自由度处理 | 单腱欠驱动 | 利用人手自然运动约束协调多个指关节 |
| 电池 | 7.4 V LiPo | 无线供电 |
| 控制器 | ESP32 | 传感采集与电机控制 |
| 电源调理 | 升降压模块维持5 V | 保证逻辑电平稳定 |

电机编码器只知道“电机/腱绳移动了多少”，不能保证手指实际完成相同位移。腱绳松弛、结构卡滞或指尖提前接触都会造成驱动端与手指端不一致，这也是论文增加StretchSense和MagSense的原因。

### 2.3 StretchSense：承力、回弹与本体感知三合一结构

| 项目 | 原文配置 |
|---|---|
| 材料 | Recreus Conductive Filaflex TPU，Shore 92A |
| 形态 | 连接各指骨环的导电扁平弹簧 |
| 机械功能 | 腱绳放松后提供被动伸展/回弹 |
| 传感功能 | 拉伸导致电阻变化，用于估计外骨骼形变和手指屈曲 |
| 测试厚度 | 0.5–2.5 mm，共5种 |
| 最终选择 | 1 mm厚度 |
| 感知范围 | 电阻约20 kΩ降至12 kΩ，变化范围约8 kΩ |
| 循环寿命 | 扩展测试计划501次，约455次后失效 |

StretchSense测的是系统内部构型，因此论文将其归为proprioceptive sensor，而不是外界接触传感器。其高精度姿态估计主要发生在较大手指运动范围内，小运动的分辨能力较弱。

## 3. MagSense磁触觉硬件结构

### 3.1 传感堆叠

```text
外部物体
   ↓ 接触/压缩
柔性TPU指腹 + 人体指腹组织        ← 可变形介质
   ↓
6 mm小型NdFeB钕磁铁              ← 嵌入远端TPU“pulp”
   ↓ 初始磁铁-传感器距离约15 mm
MMC5983MA三轴磁力计               ← 安装在指甲背侧
   ↓
ESP32采集、2 Hz低通、阈值安全控制
```

原文Fig. 2c给出的概念尺寸为：无接触时磁铁与磁力计约相距15 mm；接触压入距离为`d`时，距离变为`15 mm - d`；嵌入磁铁直径标为6 mm。

### 3.2 为什么放在“指腹—指甲”两侧

- 磁铁位于柔软指腹，能随局部接触压缩移动。
- 磁力计位于较稳定的指甲背侧，提供相对固定的参考端。
- TPU与人体指腹组织共同传递形变，减少额外独立弹性层。
- 电子元件位于背侧，避免直接承受接触磨损与冲击。

代价是人体组织也进入了传递链。不同用户的指腹厚度、软硬、佩戴预紧和传感器对准误差都会改变`B-d`映射，因此该结构天然存在个体域偏移与重复佩戴漂移。

### 3.3 信号形成机制

接触力压缩指腹后，磁铁向磁力计靠近，磁通密度`B`上升。近似偶极场关系可写为：

```math
B \propto \frac{1}{r^3}
```

因此距离`r`的小变化会产生较明显的磁场幅值变化。论文进一步比较：

```math
\frac{dB}{dx}
```

其中`x`是电机位移。较软材料会通过自身形变吸收更多位移，较硬材料会把更多变形传递到指腹，使磁铁更接近磁力计，从而形成不同的`B-x`曲线。

必须区分：

```math
\frac{dB}{dx} \neq \frac{dF}{dx}=k
```

`dB/dx`只是磁场相对于驱动位移的变化率；真正的刚度需要同步力`F`与物体形变量`x`。论文没有使用独立力传感器建立`B→F`标定，因此它验证的是材料顺应性差异，而非绝对刚度回归。

### 3.4 信号处理与动态带宽

MagSense采用截止频率2 Hz的二阶Butterworth低通滤波，目的为提高缓慢抓取与稳态压缩过程中的信号稳定性。

该参数隐含了清楚的任务取向：

| 任务 | 2 Hz低通的影响 |
|---|---|
| 缓慢抓取、接触保持 | 有利于抑制噪声、稳定阈值 |
| 材料缓慢压缩 | 可保留主要趋势 |
| 快速力变化、碰撞 | 会削弱峰值和上升沿 |
| 滑移、振动、纹理 | 很可能滤除关键高频信息 |

因此2 Hz不是磁触觉的通用预处理参数，而是针对SoFiE慢速辅助抓取任务的选择。我们的动态差分特征若采用相同截止频率，可能损失瞬态响应，后续应把截止频率作为独立消融变量。

## 4. 三层冗余如何工作

| 观测层 | 传感器 | 它真正测到什么 | 可发现的问题 |
|---|---|---|---|
| 驱动端 | 电机编码器 | 电机轴/腱绳位移 | 到达行程上限、控制命令是否执行 |
| 结构端 | StretchSense | 外骨骼背部弹簧形变 | 腱绳松弛、机械卡滞、手指实际弯曲不足 |
| 接触端 | MagSense | 指尖局部接触压缩 | 已接触物体、接触继续增强、可能过压 |

论文设置两层安全机制：

1. 编码器位置达到软件限位时阻止过伸展。
2. MagSense磁场出现超过阈值的尖峰时立即停机。

典型一致性判断可写为：

```text
编码器持续变化 + StretchSense变化很小
→ 腱绳可能松弛或机构受阻

编码器持续变化 + MagSense快速增大
→ 指尖已经接触，继续驱动可能导致过压

StretchSense显示明显弯曲 + MagSense仍接近基线
→ 手指在自由空间运动，尚未接触物体
```

## 5. 原文实验条件与实证结果

### 5.1 StretchSense台架实验

- 测试5种厚度：0.5–2.5 mm。
- 使用Shimadzu EZ Test万能试验机测力与位移。
- 使用LCR-6100测电阻，NI DAQ采集，同步MATLAB处理。
- 预紧力约0.15 N。
- 每种弹簧31个伸缩循环；首循环作为burn-in剔除。
- 位移0→40→0 mm，速度1 mm/s；回零后保持5 s。
- 1 mm弹簧在回复力与约8 kΩ感知范围之间最平衡。
- 扩展疲劳测试中约455次循环后失效。

### 5.2 MagSense泡棉实验

- 三种20 mm厚聚氨酯泡棉：10、20、30 PPI。
- 每种10次人工试验。
- 每次20 s：基线5 s→轻触5 s→压缩10 mm并保持5 s→回到接触5 s→释放。
- 轻触时磁场上升约0.5 G。
- 再压缩10 mm后，根据材料软硬升至约0.7–2 G。
- 30 PPI较硬泡棉向传感结构传递更多变形，响应最大；10 PPI软泡棉由内部形变吸收更多位移，响应较小。

这里没有同步绝对接触力，因此不能报告力MAE；也没有刚度真值和独立测试集，因此不能报告刚度回归误差或材料分类准确率。

### 5.3 五种日常物体演示

测试物体包括：

- 500 mL塑料水瓶；
- 铅笔；
- 海绵；
- 螺丝刀；
- 装有铅笔的软笔袋。

编码器、StretchSense和MagSense对不同物体产生不同的联合时序签名。作者展示了主动辅助和被动抓取中相似的整体趋势，但没有训练物体识别器，也没有给出任务准确率。

## 6. 论文已经证明与尚未证明的内容

### 已经证明

- 柔性导电弹簧可同时提供被动回弹和可测电阻响应。
- 钕磁铁+MMC5983MA结构能检测指尖接触压缩。
- 不同顺应性泡棉产生不同磁场—驱动位移响应。
- 编码器、StretchSense和MagSense能形成互补状态观测。
- 整套设备可由ESP32控制并无线佩戴运行。

### 尚未证明

- 未建立磁场到绝对接触力的标定模型。
- 未直接测量或回归绝对材料刚度。
- 未验证接触位置、剪切力或多点接触。
- 未测试跨用户、重复佩戴、磁铁错位和长期漂移。
- 未公开原始数据、代码或完整硬件仓库。
- 未验证滑移、冲击等高频动态任务。

## 7. 对我们磁触觉项目的直接启示

### 7.1 可以直接记录的硬件经验

1. **固定参考端+柔性移动端**：磁力计放在相对稳定的指甲背侧，磁铁放在柔软指腹，是结构上易理解的磁位移测量方式。
2. **电子元件避开接触面**：减少磨损和直接冲击，便于维护。
3. **软介质也是模型的一部分**：TPU和人体组织共同决定`B-F-X`关系，不能只记录磁铁与芯片参数。
4. **初始间距决定灵敏度与量程**：论文使用约15 mm初始距离和6 mm磁铁；更近通常更敏感但更易饱和、非线性更强。
5. **带宽必须与任务匹配**：2 Hz适合稳态辅助抓取，不适合我们的快速动态与差分特征路线。

### 7.2 与我们的结构差异

| SoFiE | 我们的项目 |
|---|---|
| 单磁铁+单颗三轴磁力计 | 4颗三轴磁力计阵列 |
| 主要看磁场幅值/趋势 | 利用多传感器幅值、方向、空间关系和差分特征 |
| 接触与材料顺应性区分 | 逐帧回归F/X/Y/θ |
| 人体组织参与形变传递 | 参数化磁触觉指尖结构 |
| 2 Hz稳态滤波 | 需要保留动态接触和瞬态变化 |
| 无学习模型 | MLP/CNN/seq2seq与物理先验 |

### 7.3 最值得借鉴的实验，不是立即做刚度回归

近期可做的是跨信号一致性与安全检测：

```text
原始B场幅值
多传感器方向关系
差分特征ΔB
模型输出F/X/Y/θ
```

检查这些信号在接触开始、力快速上升、释放和异常漂移时是否彼此一致。若未来要做刚度估计，应新增同步压入深度/物体形变量与刚度真值，再评估`dF/dx`，不能只添加一个“刚度输出头”。

## 8. 面向硬件复刻的参数清单

若要把SoFiE的MagSense结构作为硬件参考，至少需要完整记录：

- 磁铁：NdFeB等级、直径（论文图示6 mm）、厚度、磁化方向、剩磁；
- 磁力计：MMC5983MA、量程、采样率、安装方向；
- 初始几何：约15 mm间距、横向偏置、安装角度；
- 柔性介质：VarioShore TPU打印参数、厚度、孔隙率、硬度；
- 人体/结构接口：佩戴预紧、指腹厚度、重复佩戴定位；
- 信号链：采样频率、单位换算、2 Hz二阶Butterworth实现细节；
- 标定真值：若估力需力传感器，若估刚度需同步力与压入深度；
- 漂移测试：跨用户、跨天、重装、温度、磁铁错位和材料疲劳。

论文只披露了其中一部分，因此可以借鉴结构思想，但不能仅凭本文参数完整复刻出可比较的力/位置传感器。
